项目概览

一个以「三国」为题材的全栈演示项目：用户以「将军」身份注册/登录，进入「中军大帐」首页， 可浏览英雄榜（武将图鉴）、军机要务（任务清单）、烽火快报（资讯流），并支持跨类别全局搜索。 所有数据由后端从 MySQL 实时读取，前端不含任何硬编码假数据。

前端：Vue 3 + Vite 6（状态驱动，无 vue-router） 后端：Spring Boot 3.4.5 + MyBatis-Plus 数据库：MySQL 8.0.46（库名 sanguo，4 张表）
演示账号：云长 / danfeng123（阵营：蜀汉）。密码以 BCrypt 加密存储。

四大阵营各有专属主色，登录后根据用户所属阵营动态切换全局主色 （技术实现：在 <html data-faction="..."> 上挂载，CSS 变量 --primary 随之变化）。

汉室 han
曹魏 wei
蜀汉 shu
东吴 wu

③ 明暗双主题 + 书法字体

支持「暗（水墨夜景）/ 亮（宣纸亮色）」切换，选择记忆在 localStorage，切换时带 0.45s 平滑过渡。

马善政 标题 站酷小薇 艺术 思源宋体 正文

④ 微交互

点击控件触发「墨韵涟漪」ink-ripple 扩散效果；支持 prefers-reduced-motion 无障碍降级。 全部设计令牌（颜色/间距/圆角/阴影/动效）集中在 tokens.css，组件只引用语义变量，便于统一换肤。

已完成功能（每个都带真实演示）

功能一 · 将军入册 / 登录

前端 SanguoLogin.vue后端 /api/register · /api/login

注册时前端校验名号≥2字、密令≥6位，后端二次兜底校验 + 名号查重，密码以 BCrypt 加密入库。 登录成功后返回用户信息（不含密码），前端存入 sessionStorage 并按阵营切换主题色。

演示：以演示账号登录（POST /api/login）

→ POST /api/login  {"username":"云长","password":"danfeng123"}
← 200  {
  "success": true,
  "message": "点兵入帐成功",
  "data": { "username":"云长", "faction":"shu",
            "factionName":"蜀汉", "createTime":"2026-10-16" }
}

功能二 · 中军大帐首页（登录后主界面）

前端 SanguoHome.vue后端 /api/stats · /api/heroes · /api/tasks · /api/news · /api/search

2.1 天下大势（GET /api/stats）

统计将军总数与各大阵营人数，驱动首页「天下大势」卡片。

→ GET /api/stats
← 200  { "success":true, "data": { "total":1,
        "byFaction": {"han":0,"wei":0,"shu":1,"wu":0} } }

2.2 英雄榜（GET /api/heroes · /api/heroes/meta）

武将图鉴，支持「关键词 + 阵营（一级）+ 类型（二级）」分级筛选；/meta 提供筛选器元数据与各级数量。

→ GET /api/heroes/meta
← 200  { "factions":[
          {"key":"han","name":"汉室","count":4},
          {"key":"wei","name":"曹魏","count":6},
          {"key":"shu","name":"蜀汉","count":6},
          {"key":"wu","name":"东吴","count":6}],
        "types":[
          {"name":"谋士","count":5},{"name":"猛将","count":13},
          {"name":"君主","count":3},{"name":"权臣","count":1}] }

→ GET /api/heroes?faction=shu&type=猛将
← 200  关羽(美髯公/汉寿亭侯) · 张飞(万人敌) · 赵云(常胜将军) … 共 5 员

2.3 军机要务（GET /api/tasks）

任务清单，支持关键词 / 分类（军机·后勤·外交·巡查·军械）/ 完成状态筛选。

→ GET /api/tasks?category=军机
← 200  [ "操演：演练八门金锁阵"(缓),
        "侦察：探马哨骑回报敌情"(急),
        "练兵：三军操演"(已完成),
        "点卯：清点麾下兵马"(已完成) ] 共 4 条

2.4 烽火快报（GET /api/news）

资讯流，支持关键词 / 分类（民生·战报·密报·异象）筛选。

→ GET /api/news?category=战报
← 200  [ "校场：新募乡勇习练枪棒",
        "江边：水师操练，战船列阵如墙",
        "烽火台：今日边关无事，秋高马肥" ] 共 3 则

2.5 全局搜索（GET /api/search）

跨「武将 / 要务 / 快报」三类检索，分组返回，驱动首页顶部搜索下拉。

→ GET /api/search?keyword=赵云
← 200  { "heroes":[ 赵云(常胜将军/镇军将军) ],
        "tasks":[], "news":[] }
