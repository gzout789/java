烽烟三国杀

武 将 设 定 集 · 典 故 驱 动 版
汉末动荡，汉主临危，忠良护主、群雄伐汉、隐客伺机。诸将各展韬略，以牌为兵，决一胜负。
设计原则：每个技能 = 一条可考的历史典故 + 一段可执行的结算逻辑。 技能标签沿用四类：【常策】锁定技 /【奇谋】主动技 /【应策】响应技 /【秘计】限定技（一局一次）。 全部描述均已规避原版名词，可直接作为自研代码的需求文档。

刘备汉5 体力（主公 +1）辅助 / 续航
仁德奇谋
出牌阶段，每阶段限一次

你可以将任意数量的手牌交给一名其他角色；若一次性给出不少于 2 张，你回复 1 点体力。

典故　建安十三年曹操南征，刘备"携民渡江"，日行十余里而不弃百姓（《三国志·先主传》）；又三让徐州，以仁德立身。散财而得人心，故"给牌"换"回血"。
昭烈主公技·应策
其他汉势力角色的出牌阶段

其他汉势力角色可以交给你一张手牌，然后该角色摸一张牌。

典故　桃园结义、得人死力——关羽挂印封金、赵云长坂救主，皆因刘备能"得众心"。主公技象征汉室正统的号召力。
关羽汉4 体力强攻 / 破防
武圣应策
你使用或打出【击】时

你可以将任意一张手牌当作【击】打出；若该牌为红色，目标需打出两张【挡】才能抵消。

典故　建安五年白马之围，"羽望见良麾盖，策马刺良于万众之中，斩其首还，绍诸将莫能当者"（《三国志·关羽传》）。赤色应赤兔马与赤胆忠心，万军之中取上将首级，寻常招架挡不住。
单刀秘计
出牌阶段，一局一次

弃置一张手牌，视为对攻击范围内一名角色使用一张【击】，此【击】不可被【挡】抵消；若目标因此进入濒死，你摸 2 张牌。

典故　建安二十年鲁肃索荆州，关羽"单刀赴会"，只带周仓与数骑赴吴营，词色慷慨，肃等慑服（《三国志·鲁肃传》裴注）。一人一刀，压得对方无法回应。
赵云汉4 体力攻守兼备
龙胆应策
你需要使用【击】或【挡】时

你可以将【击】当作【挡】使用，或将【挡】当作【击】使用。

典故　建安十三年长坂坡，赵云怀抱后主、保护甘夫人，"皆得免难"；刘备赞曰"子龙一身都是胆也"（《云别传》）。七进七出，攻即是守、守即是攻。
单骑救主秘计
一名其他角色进入濒死时，一局一次

你可以弃置所有手牌，令其体力回复至 1 点，并令其摸 2 张牌。

典故　长坂坡单骑冲阵救出阿斗——"弃全部身家，换一人活命"，故代价是清空手牌。
诸葛亮汉3 体力控制 / 控牌
空城常策
锁定技，永久生效

当你没有手牌时，你不能成为【击】与瞬发计略的目标。

典故　街亭失守后，亮"凭栏而坐，焚香操琴"，司马懿疑有伏兵而退（演义第九十五回，本事见《三国志》裴松之注引"郭冲三事"）。空手而坐，无人敢攻。
观星奇谋
出牌阶段限一次

你可以观看牌堆顶的 3 张牌，然后以任意顺序放回牌堆顶或牌堆底。

典故　"亮夜观天象"，借东风、草船借箭皆赖知天时；星象即牌堆——看得见的未来。
七星秘计
你进入濒死时，一局一次

你可以弃置所有牌，将体力回复至 2 点并摸 2 张牌。

典故　建兴十二年五丈原，亮"禳星祈寿"，设七星灯祈禳延寿（演义第一〇三回）。以全部身家换一线生机。

曹魏阵营掠夺、压制、反伤

曹操魏4 体力掠夺 / 压制
收编应策
你受到创伤后

你可以获得伤害来源的一张手牌，或装备区的一张牌。

典故　初平三年，曹操破青州黄巾，"受降卒三十余万……收其精锐者，号为青州兵"（《三国志·武帝纪》）。敌人的东西，转手就是自己的兵。
挟天子奇谋
出牌阶段限一次

弃置一张手牌，指定一名其他角色，令其本回合的用兵阶段不能使用或打出【击】。

典故　建安元年，曹操迎汉献帝于洛阳，"挟天子以令诸侯"——不是打你，是不许你动手。
夏侯惇魏4 体力反伤 / 强硬
拔矢啖睛应策
你受到【击】造成的创伤后

你可以令伤害来源选择一项：① 弃置两张手牌；② 受到 1 点创伤。

典故　建安二年征吕布，"惇为流矢所中，伤左目"，拔箭啖睛曰"父精母血，不可弃也"（《三国志·夏侯惇传》裴注引《魏略》）。受了伤也要咬着牙打回去。
刚烈常策
锁定技

你受到【援】的回复量 +1（不超过体力上限）。

典故　惇性清俭刚烈，得赏赐辄分与将士——恢复力源自其悍勇与得众。
司马懿魏3 体力判定操控 / 收割
鬼才应策
任意角色的判定牌生效前

你可以打出一张手牌，代替该判定牌。

典故　懿"鹰视狼顾"，善揣度人心、预判局势——亮送巾帼之服激其出战，懿笑问其寝食，已知其命不久（《晋书·宣帝纪》）。看穿对手的底牌，就有能力换掉它。
高平陵秘计
一名角色阵亡时，一局一次

你可以获得该角色的所有手牌与装备牌，并回复 1 点体力。

典故　正始十年，懿趁曹爽陪帝谒高平陵，闭城门、据武库，一举夺权，尽收曹爽之众（《晋书·宣帝纪》）。他人之死，即我之资。

孙吴阵营爆发、装备、控场

周瑜吴3 体力爆发 / 群体伤害
英姿奇谋
你的征粮阶段

你摸牌时多摸一张（征粮阶段摸 3 张）。

典故　"遥想公瑾当年，小乔初嫁了，雄姿英发，羽扇纶巾"——苏轼《念奴娇·赤壁怀古》。才俊从容，粮草自足。
火烧赤壁秘计
出牌阶段，一局一次

弃置一张红色手牌，指定至多两名其他角色各受到 1 点创伤，且不能被【挡】之外的牌阻止；此后你弃置一张装备牌（若有）。

典故　建安十三年，黄盖诈降纵火，"顷之，烟炎张天，人马烧溺死者甚众"（《三国志·周瑜传》）。一把火烧尽连环战船，救无可救。
反间应策
你成为【击】的目标且结算后

弃置一张手牌，令使用者交给你一张手牌；若其不交，你对其造成 1 点创伤。

典故　赤壁战前，瑜利用蒋干"盗书"，使曹操疑杀水军都督蔡瑁、张允（《江表传》）。借你之手，反噬你自己。
孙尚香吴3 体力装备流 / 治疗
枭姬应策
你失去装备区里的一张牌后

你可以摸两张牌。

典故　孙夫人"才捷刚猛，有诸兄之风"，侍婢百余人皆执刀侍立，刘备每入内常凛凛（《三国志·法正传》）。武备被夺，反而愈战愈勇。
联姻奇谋
出牌阶段限一次

弃置两张手牌，令一名其他角色与你各回复 1 点体力；若该角色为汉势力，你额外摸一张牌。

典故　建安十四年，孙权嫁妹于刘备，孙刘联盟以抗曹（《三国志·先主传》）。一段政治婚姻，换来双方喘息。
陆逊吴3 体力控场 / 计略抗性
谦冲常策
锁定技

你不能成为【惑敌】的目标；你受到计略牌造成的创伤 -1（最低 1 点）。

典故　陆逊"意思深长，未有远近之议"，为人谦逊沉稳、不露锋芒；孙权称其"有超世之功者，必应光远之明"。沉得住气，故不受激将、不为流言所动。
夷陵秘计
出牌阶段，一局一次

弃置所有红色手牌，指定至多三名其他角色各受到 1 点创伤，并各弃置一张装备牌（若有）。

典故　章武二年，逊以火攻破蜀军，"乃敕各持一把茅，以火攻拔之……破其四十余营"（《三国志·陆逊传》）。火烧连营七百里，营寨尽毁——故附带弃装备。

群雄阵营极限强攻、操控、治疗

吕布群4 体力极限强攻
无双应策
你使用【击】指定目标时

目标需打出两张【挡】才能抵消此【击】；若只打出一张，仍受 1 点创伤。

辕门射戟秘计
出牌阶段，一局一次

弃置一张【击】，令所有其他角色各选择一项：弃置一张手牌，或受到 1 点创伤。

典故　建安元年，袁术遣纪灵攻刘备，布于营门"举弓射戟，正中小支"，诸将惊呼"将军天威也"，遂罢兵解斗（《三国志·吕布传》）。一箭立威，全场噤声。
貂蝉群3 体力操控 / 离间
离间奇谋
出牌阶段限一次

弃置一张牌，指定两名男性角色 A、B，令 A 对 B 使用一张【击】；若 A 无法或不愿如此做，A 失去 1 点体力，然后你摸一张牌。

典故　司徒王允设连环美人计，先许貂蝉于吕布，后献于董卓，使二人反目，终致吕布手刃董卓（演义第八、九回）。不动一刀，借刀杀人。
闭月常策
你的收阵阶段

你的回合结束时，你摸一张牌。

典故　貂蝉有"闭月"之貌——月亮见其美貌，自愧不如，隐入云中。美貌本身就是持续的资源。
华佗群3 体力治疗 / 救援
青囊奇谋
出牌阶段，每阶段限两次

你可以弃置一张手牌，令一名已受伤的角色回复 1 点体力。

典故　华佗"精方药……合汤不过数种"，创麻沸散、五禽戏（《三国志·方技传》）；狱中所著《青囊书》为医家至宝。弃一张牌换一条命，正是医者本色。
刮骨应策
一名角色进入濒死时

你可以将一张红色手牌当作【援】对其使用。

典故　关羽左臂为流矢所中，医曰"当破臂作创，刮骨去毒"，羽"伸臂令医劈之……割炙引酒，言笑自若"（《三国志·关羽传》）。危难之际，一刀一药救人于将死。

武将数据示例（JSON）： 
{
  "id": "guanyu", "name": "关羽", "faction": "汉", "hp": 4,
  "skills": [
    { "name": "武圣", "type": "应策", "trigger": "on_use_card",
      "condition": "intent == '击'",
      "effect": "treat_as(card,'击'); if card.color=='red': required_block=2",
      "allusion": "白马之围，策马刺良于万众之中" },
    { "name": "单刀", "type": "秘计", "trigger": "on_phase", "phase": "用兵",
      "once_per_game": true,
      "effect": "discard(1); force_hit(target, unblockable=True)",
      "allusion": "单刀赴会，词色慷慨，肃等慑服" }
  ]
}
结算钩子（与六阶段回合对齐）： 
on_round_start (启策) → 常策结算
on_judge       (判定) → 鬼才等改判钩子
on_draw        (征粮) → 英姿、断粮判定
on_play        (用兵) → 奇谋、应策主战场
on_discard     (收兵) → 手牌上限 = 体力
on_round_end   (收阵) → 闭月等收尾技
on_damage / on_dying / on_death
             → 拔矢啖睛、七星、刮骨、单骑救主、高平陵
