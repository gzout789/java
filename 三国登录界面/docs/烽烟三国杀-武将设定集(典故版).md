## 一、汉室阵营（4 名）

### 刘备 · 汉 · 5 体力（汉主，体力上限 +1）· 定位：辅助/续航

**奇谋【仁德】** · 出牌阶段，每阶段限一次
> 效果：你可以将任意数量的手牌交给一名其他角色；若一次性给出不少于 2 张，你回复 1 点体力。
> 典故：建安十三年，曹操南征，刘备"携民渡江"，日行十余里而不弃百姓（《三国志·先主传》）；又三让徐州，以仁德立身。散财而得人心，故"给牌"换"回血"。

```python
def skill_rende(ctx, me, cards, target):
    if ctx.phase != '用兵' or me.skill_used['仁德']: return
    if len(cards) >= 2:
        target.hand += cards
        me.hand -= cards
        if me.hp < me.max_hp: me.hp += 1
        me.skill_used['仁德'] = True
```

**应策（主公技）【昭烈】** · 触发：其他汉势力角色的出牌阶段
> 效果：其他汉势力角色可以交给你一张手牌，然后该角色摸一张牌。
> 典故：桃园结义、得人死力——关羽挂印封金、赵云长坂救主，皆因刘备能"得众心"。主公技象征汉室正统的号召力。

```python
def skill_zhaolie(ctx, me, donor, card):
    if donor.identity == '忠良' or donor.faction == '汉':
        me.hand.append(card); donor.hand.remove(card)
        donor.draw(1)
```

### 关羽 · 汉 · 4 体力 · 定位：强攻/破防

**应策【武圣】** · 触发：你使用或打出【击】时；你成为【击】目标需要出【挡】时
> 效果：① 你可以将任意一张手牌当作【击】打出；② 若以此法使用的牌为**红色**，目标需打出**两张【挡】**才能抵消。
> 典故：建安五年白马之围，"羽望见良麾盖，策马刺良于万众之中，斩其首还，绍诸将莫能当者"（《三国志·关羽传》）。赤色应赤兔马与赤胆忠心，斩颜良于万众之中——寻常招架挡不住。

```python
def skill_wusheng(ctx, me, card):
    if intent == '击':
        allow_treat_as(card, '击')
        if card.color == 'red':
            ctx.required_block[target] = 2   # 需两张【挡】
```

**秘计【单刀】** · 出牌阶段，一局一次
> 效果：你可以弃置一张手牌，视为对**攻击范围内一名角色**使用一张【击】，此【击】不可被【挡】抵消；若目标因此进入濒死，你摸 2 张牌。
> 典故：建安二十年，鲁肃索荆州，关羽"单刀赴会"，只带周仓与数骑赴吴营，词色慷慨，肃等慑服（《三国志·鲁肃传》裴注）。一人一刀，压得对方无法回应。

### 赵云 · 汉 · 4 体力 · 定位：攻守兼备

**应策【龙胆】** · 触发：你需要使用【击】或【挡】时
> 效果：你可以将【击】当作【挡】使用，或将【挡】当作【击】使用。
> 典故：建安十三年长坂坡，赵云怀抱后主、保护甘夫人，"皆得免难"；刘备赞曰"子龙一身都是胆也"（《云别传》）。七进七出，攻即是守、守即是攻。

```python
def skill_longdan(ctx, me, card, need):
    if need == '挡' and card.name == '击': return treat_as(card, '挡')
    if need == '击' and card.name == '挡': return treat_as(card, '击')
```

**秘计【单骑救主】** · 一局一次 · 触发：一名其他角色进入濒死时
> 效果：你可以弃置所有手牌，令其体力回复至 1 点，并令其摸 2 张牌。
> 典故：长坂坡单骑冲阵救出阿斗——"弃全部身家，换一人活命"，故代价是清空手牌。

### 诸葛亮 · 汉 · 3 体力 · 定位：控制/控牌

**常策【空城】** · 锁定技
> 效果：当你没有手牌时，你不能成为【击】与瞬发计略的目标。
> 典故：街亭失守后，诸葛亮"乃披鹤氅，戴纶巾，引二小童携琴一张，凭栏而坐，焚香操琴"，司马懿疑有伏兵而退（演义第九十五回，本事见《三国志》裴松之注所引"郭冲三事"）。空手而坐，无人敢攻。

**奇谋【观星】** · 出牌阶段限一次
> 效果：你可以观看牌堆顶的 3 张牌，然后将其以任意顺序放回牌堆顶或牌堆底。
> 典故："亮夜观天象"，借东风、草船借箭皆赖知天时；星象即牌堆——看得见的未来。

**秘计【七星】** · 一局一次 · 触发：你进入濒死时
> 效果：你可以弃置所有牌，将体力回复至 2 点并摸 2 张牌。
> 典故：建兴十二年五丈原，亮"禳星祈寿"，设七星灯祈禳延寿（《三国演义》第一〇三回）。以全部身家换一线生机。

## 二、曹魏阵营（3 名）

### 曹操 · 魏 · 4 体力 · 定位：掠夺/压制

**应策【收编】** · 触发：你受到创伤后
> 效果：你可以获得伤害来源的一张手牌或装备区的一张牌。
> 典故：初平三年，曹操击破青州黄巾，"受降卒三十余万，男女百余万口，收其精锐者，号为青州兵"（《三国志·武帝纪》）。敌人的东西，转手就是自己的兵。

**奇谋【挟天子】** · 出牌阶段限一次
> 效果：你可以弃置一张手牌，指定一名其他角色，令其本回合的用兵阶段不能使用或打出【击】。
> 典故：建安元年，曹操迎汉献帝于洛阳，"挟天子以令诸侯"，以朝廷诏命压制四方诸侯——不是打你，是不许你动手。

```python
def skill_xietianzi(ctx, me, target):
    if ctx.phase != '用兵' or me.skill_used['挟天子']: return
    me.discard(1)
    target.flag['禁用击'] = True   # 本回合失效
```

### 夏侯惇 · 魏 · 4 体力 · 定位：反伤/强硬

**应策【拔矢啖睛】** · 触发：你受到【击】造成的创伤后
> 效果：你可以令伤害来源选择一项：① 弃置两张手牌；② 受到 1 点创伤。若其体力因此变为 0，仍照常结算濒死。
> 典故：建安二年征吕布，"惇为流矢所中，伤左目"，拔箭啖睛，"父精母血，不可弃也"（《三国志·夏侯惇传》裴注引《魏略》）。受了伤也要咬着牙打回去。

**常策【刚烈】** · 锁定技
> 效果：你受到的【援】回复量 +1（最多不超过体力上限）。
> 典故：惇"虽在军旅，亲迎师受业"，性清俭刚烈，得赏赐辄分与将士——恢复力源自其悍勇。

### 司马懿 · 魏 · 3 体力 · 定位：判定操控/收割

**应策【鬼才】** · 触发：任意角色的判定牌生效前
> 效果：你可以打出一张手牌，代替该判定牌。
> 典故：司马懿"鹰视狼顾"，善揣度人心、预判局势——诸葛亮送巾帼之服激其出战，懿笑问"孔明寝食及事之烦简"，已知其命不久（《晋书·宣帝纪》）。看穿对手的底牌，就有能力换掉它。

**秘计【高平陵】** · 一局一次 · 触发：一名角色阵亡时
> 效果：你可以获得该角色的所有手牌与装备牌，并回复 1 点体力。
> 典故：正始十年，司马懿趁曹爽陪帝谒高平陵，闭城门、据武库，一举夺权，尽收曹爽之众（《晋书·宣帝纪》）。他人之死，即我之资。

## 三、孙吴阵营（3 名）

### 周瑜 · 吴 · 3 体力 · 定位：爆发/群体伤害

**奇谋【英姿】** · 触发：你的征粮阶段
> 效果：你摸牌时多摸一张（即征粮阶段摸 3 张）。
> 典故："遥想公瑾当年，小乔初嫁了，雄姿英发，羽扇纶巾"——苏轼《念奴娇·赤壁怀古》。才俊从容，粮草自足。

**秘计【火烧赤壁】** · 一局一次 · 出牌阶段
> 效果：你可以弃置一张红色手牌，指定至多两名其他角色，各受到 1 点创伤，且此创伤不能使用【挡】或【援】之外的任何方式阻止；此后你弃置一张装备区的牌（若有）。
> 典故：建安十三年，周瑜部将黄盖诈降纵火，"顷之，烟炎张天，人马烧溺死者甚众"（《三国志·周瑜传》）。一把火烧尽连环战船，救无可救。

**应策【反间】** · 触发：你成为【击】的目标且该【击】结算后
> 效果：你可以弃置一张手牌，令使用【击】的角色交给你一张手牌；若其不交，你对其造成 1 点创伤。
> 典故：赤壁战前，周瑜利用蒋干"盗书"，使曹操疑杀水军都督蔡瑁、张允（《三国演义》第四十五回，本事见《江表传》）。借你之手，反噬你自己。

### 孙尚香 · 吴 · 3 体力 · 定位：装备流/治疗

**应策【枭姬】** · 触发：你失去装备区里的一张牌后
> 效果：你可以摸两张牌。
> 典故：孙夫人"才捷刚猛，有诸兄之风"，侍婢百余人皆执刀侍立，刘备每入内常凛凛（《三国志·法正传》）。武备被夺，反而愈战愈勇——失去装备，摸牌再战。

**奇谋【联姻】** · 出牌阶段限一次
> 效果：你可以弃置两张手牌，令一名其他角色与你各回复 1 点体力；若该角色为汉势力，你额外摸一张牌。
> 典故：建安十四年，孙权嫁妹于刘备，孙刘联盟以抗曹（《三国志·先主传》）。一段政治婚姻，换来双方喘息。

### 陆逊 · 吴 · 3 体力 · 定位：控场/计略抗性

**常策【谦冲】** · 锁定技
> 效果：你不能成为【惑敌】的目标；你受到的计略牌造成的创伤 -1（最低 1 点）。
> 典故：陆逊"意思深长，未有远近之议"，为人谦逊沉稳，不露锋芒；孙权称其"有超世之功者，必应光远之明"。沉得住气，故不受激将、不为流言所动。

**秘计【夷陵】** · 一局一次 · 出牌阶段
> 效果：你可以弃置所有红色手牌，指定至多三名其他角色，各受到 1 点创伤，并各弃置一张装备牌（若有）。
> 典故：章武二年，陆逊以火攻破蜀军，"乃敕各持一把茅，以火攻拔之。一尔势成，通率诸军同时俱攻，斩张南、冯习及胡王沙摩柯等首，破其四十余营"（《三国志·陆逊传》）。火烧连营七百里，营寨尽毁——故附带弃装备。

## 四、群雄阵营（3 名）

### 吕布 · 群 · 4 体力 · 定位：极限强攻

**应策【无双】** · 触发：你使用【击】指定目标时
> 效果：目标需打出**两张【挡】**才能抵消此【击】；若其只打出一张，仍受到 1 点创伤。
> 典故："人中吕布，马中赤兔"（《三国志·吕布传》裴注引《曹瞒传》）。布"便弓马，膂力过人，号为飞将"，寻常防御挡他不住。

**秘计【辕门射戟】** · 一局一次 · 出牌阶段
> 效果：你可以弃置一张【击】，令所有其他角色各选择一项：弃置一张手牌，或受到 1 点创伤。
> 典故：建安元年，袁术遣纪灵攻刘备，吕布于营门"举弓射戟，正中小支"，诸将惊呼"将军天威也"，遂罢兵解斗（《三国志·吕布传》）。一箭立威，全场噤声。

---

### 貂蝉 · 群 · 3 体力 · 定位：操控/离间

**奇谋【离间】** · 出牌阶段限一次
> 效果：你可以弃置一张牌，指定两名男性角色 A、B，令 A 对 B 使用一张【击】；若 A 无法或不愿如此做，A 失去 1 点体力，然后你摸一张牌。
> 典故：司徒王允设连环美人计，先许貂蝉于吕布，后献于董卓，使二人反目，终致吕布手刃董卓（《三国演义》第八、九回）。不动一刀，借刀杀人。

**常策【闭月】** · 锁定技 · 触发：你的收阵阶段
> 效果：你的回合结束时，你摸一张牌。
> 典故：貂蝉有"闭月"之貌——"月亮见其美貌，自愧不如，隐入云中"。美貌本身就是持续的资源。

---

### 华佗 · 群 · 3 体力 · 定位：治疗/救援

**奇谋【青囊】** · 出牌阶段
> 效果：你可以弃置一张手牌，令一名已受伤的角色回复 1 点体力。每阶段限发动两次。
> 典故：华佗"精方药，其疗疾，合汤不过数种"，创麻沸散、五禽戏（《三国志·方技传》）；狱中所著《青囊书》为医家至宝。弃一张牌换一条命，正是医者本色。

**应策【刮骨】** · 触发：一名角色进入濒死时
> 效果：你可以将一张红色手牌当作【援】对其使用。
> 典故：关羽左臂为流矢所中，"医曰：当破臂作创，刮骨去毒"，羽"伸臂令医劈之，时适请诸将饮食相对，臂血流离，而羽割炙引酒，言笑自若"（《三国志·关羽传》）。危难之际，一刀一药救人于将死。

## 七、可扩展方向（按此框架继续加）

1. **主公技体系**：为刘备之外的汉主候选（如刘禅、孙权称帝）配专属号召技
2. **国战模式**：去掉身份，按势力组队，武将势力即阵营
3. **宝物/坐骑扩展牌**：赤兔马（吕布专属）、青囊书（华佗专属）
4. **体力流失机制**：与"受到创伤"区分，用于【惊雷】、貂蝉【离间】等不触发反伤类应策的结算
5. **连营传导类计略**：以陆逊【夷陵】为模板扩展多目标连锁牌
