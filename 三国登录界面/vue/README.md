# 三国主题登录界面 · Vue 工程

基于 **Vue 3 + Vite** 的三国（汉风）主题登录界面。水墨山水背景、朱红描金配色，支持阵营主题切换。

> 优化待办与工作起点见项目根目录 **`../优化清单.md`**；本工程的技术铁律见 **`PROJECT_NOTES.md`**。

## 功能特性

- 水墨山水 SVG 背景 + 飘动云雾动画（零图片依赖，离线可用）
- **登录 / 注册 同屏切换**：卡片顶部「登录 / 注册」标签页，注册含「再验密令」与一致性校验
- 阵营主题一键切换：**汉 / 魏 / 蜀 / 吴**（主色调随之变化，注册时即选定阵营）
- **印章随阵营联动**：左上角印章文字随所选阵营（汉/魏/蜀/吴）实时变化
- **字段级内联校验**：账号/密令为空、密令过短（<6 位）、两次密令不一致，直接在输入框下方红字提示
- **注册密码强度条**：弱 / 中 / 强 / 极强，跟随主题色
- **登录成功「盖印」动画**：成功后全屏落下一枚阵营印章 + 「入帐成功」
- **演示账号一键填入**：登录页「试看」一键填入测试账号，方便预览
- **忘记密令提示**：「忘了密令？」给出烽火台主题提示（占位，可对接找回接口）
- 「铭记吾名」记住账号（`localStorage` 持久化）
- 密码显示 / 隐藏切换
- 登录加载态 + 毛笔风 toast 提示
- 响应式布局，适配窄屏；并支持 `prefers-reduced-motion` 动画降级

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器（默认 http://localhost:5173，自动打开浏览器）
npm run dev

# 构建生产包到 dist/
npm run build

# 本地预览构建产物
npm run preview
```

## 一键启动（Windows）

### 推荐方式：前后端一起启动

项目根目录提供了 **`一键启动.bat`**（GBK 编码），双击即可：

1. 自动检查并启动后端（Spring Boot，`D:\workSpace\springBootTest`，端口 8081，MySQL/数据库/表/演示账号全部自动初始化）
2. 自动启动前端开发服务器（端口 5173）并打开浏览器
3. 演示账号：**云长 / danfeng123**（登录页「试看」一键填入）

停止服务请双击 **`一键停止.bat`**（同时停止 5173 前端和 8081 后端）。

### 只启动前端

项目根目录的 **`启动.bat`** 仅启动前端；桌面的 **`三国登录界面-启动.bat`** 与之等效（已写死项目路径）。

后端单独的启动/停止/重新打包脚本在后端项目目录 `D:\workSpace\springBootTest\`（也有同步副本在本目录 `springBootTest\` 下）。

## 中军大帐首页（登录后）

登录成功「盖印」后进入 `SanguoHome.vue` 首页（2026-10-12 改版）：

- **导航栏**：总览 / 英雄榜 / 军机要务 / 烽火快报 四个视图切换（纯前端 tab，无路由依赖）
- **搜索栏**：顶栏全局搜索武将 / 要务 / 快报，实时分组下拉，点击结果直达对应视图并按关键词过滤；`Esc` 或 ✕ 清除
- **英雄榜**：22 位三国名将卡片（名号 / 雅号 / 事迹），可按 汉 / 魏 / 蜀 / 吴 阵营筛选
- **总览**：迎将辞（按时辰问候）、将军档案（login 返回）、天下大势（`GET /api/stats` 实时人数）、要务 / 快报摘要卡（点标题进完整列表）
- 顶栏：阵营印章 + 将军名号 + 退出按钮；登录态存 `sessionStorage`（`sg_session`），刷新不掉线，关标签页即退出
- 风格与登录页一致：水墨山水背景、朱红描金、阵营主题联动、响应式 + `prefers-reduced-motion` 降级
